# project-antrian
Project by Acha Azarya Salissing

Program di atas merupakan sebuah aplikasi Sistem Manajemen Parkir berbasis bahasa pemrograman C++ yang dirancang untuk membantu proses pengelolaan kendaraan pada area parkir secara lebih teratur dan efisien. Program ini dibuat menggunakan konsep Object Oriented Programming (OOP) dan memanfaatkan beberapa struktur data penting seperti Queue (antrian) dan Stack (tumpukan). Sistem ini mampu menangani proses kendaraan masuk, kendaraan keluar, pencarian kendaraan, hingga penyimpanan riwayat parkir terakhir. Dengan adanya program ini, proses pengelolaan parkir yang biasanya dilakukan secara manual dapat menjadi lebih cepat, terstruktur, dan mudah dipahami.

Pada bagian awal program terdapat menu utama yang berfungsi sebagai pusat kontrol sistem. Menu tersebut menampilkan beberapa pilihan fitur seperti menambah kendaraan, kendaraan masuk parkir, kendaraan keluar parkir, melihat antrian kendaraan, melihat riwayat terakhir, mencari kendaraan berdasarkan plat nomor, dan keluar dari program. Program menggunakan perulangan do while sehingga menu akan terus tampil sampai pengguna memilih opsi keluar. Setiap pilihan menu akan menjalankan fungsi tertentu yang telah dibuat di dalam class Parkir.

Program ini menggunakan sebuah struct bernama Kendaraan untuk menyimpan data kendaraan. Struct tersebut berisi beberapa atribut seperti plat, jenis, jamMasuk, dan jamKeluar. Data kendaraan inilah yang nantinya diproses oleh sistem parkir. Selain itu, program juga menggunakan class Parkir yang berisi berbagai fungsi untuk mengatur seluruh aktivitas parkir. Dengan penggunaan class, kode program menjadi lebih rapi, terstruktur, dan mudah dikembangkan kembali di masa mendatang.

Pada fitur Tambah Kendaraan, pengguna dapat memasukkan data kendaraan seperti plat nomor, jenis kendaraan, dan jam masuk kendaraan. Sistem akan memeriksa apakah jenis kendaraan yang dimasukkan adalah “motor” atau “mobil”. Jika valid, maka kendaraan akan dimasukkan ke dalam antrian masuk parkir menggunakan konsep Queue. Program juga menampilkan tarif parkir berdasarkan jenis kendaraan, yaitu motor sebesar Rp2000 per jam dan mobil sebesar Rp4000 per jam. Jika kapasitas antrian sudah penuh, maka sistem akan menampilkan pesan bahwa antrian masuk penuh.

Fitur Kendaraan Masuk Parkir digunakan untuk memindahkan kendaraan dari antrian masuk ke area parkir utama. Sistem mengambil kendaraan pertama dari antrian masuk menggunakan prinsip FIFO (First In First Out), yaitu kendaraan yang pertama masuk antrian akan diproses terlebih dahulu. Setelah itu kendaraan akan dimasukkan ke antrian parkir. Jika area parkir penuh, maka kendaraan tidak dapat diproses masuk. Dengan penggunaan Queue, sistem parkir menjadi lebih tertib karena kendaraan diproses sesuai urutan kedatangan.

Pada fitur Kendaraan Keluar Parkir, sistem akan memproses kendaraan yang keluar dari area parkir. Program meminta pengguna memasukkan jam keluar kendaraan, kemudian menghitung lama parkir berdasarkan selisih antara jam keluar dan jam masuk. Setelah itu sistem menghitung total biaya parkir sesuai jenis kendaraan. Jika kendaraan adalah motor maka tarif dihitung Rp2000 per jam, sedangkan mobil Rp4000 per jam. Setelah pembayaran selesai, kendaraan akan dihapus dari antrian parkir dan datanya disimpan ke dalam riwayat parkir menggunakan struktur data Stack.

Fitur Lihat Antrian Kendaraan digunakan untuk menampilkan seluruh kendaraan yang sedang berada dalam antrian masuk maupun kendaraan yang sedang berada di area parkir. Program akan menampilkan plat nomor dan jenis kendaraan satu per satu. Jika tidak ada kendaraan dalam antrian atau parkiran kosong, maka sistem akan memberikan informasi bahwa data kosong. Fitur ini membantu pengguna untuk memantau kondisi parkiran secara langsung.

Program juga memiliki fitur Riwayat Terakhir yang memanfaatkan struktur data Stack. Data kendaraan yang sudah keluar parkir akan disimpan ke dalam stack sebagai riwayat. Karena menggunakan konsep LIFO (Last In First Out), maka data kendaraan terakhir yang keluar akan muncul pertama kali saat riwayat ditampilkan. Fitur ini berguna untuk melihat aktivitas kendaraan terakhir yang diproses oleh sistem.

Selain itu terdapat fitur Cari Kendaraan berdasarkan plat nomor. Pada fitur ini pengguna memasukkan plat kendaraan yang ingin dicari, kemudian sistem akan melakukan pencarian pada area parkir. Jika kendaraan ditemukan, maka sistem akan menampilkan pesan bahwa kendaraan ditemukan di parkiran. Sebaliknya, jika tidak ditemukan maka sistem akan memberikan informasi bahwa kendaraan tidak ada di area parkir. Fitur ini membantu petugas dalam memantau keberadaan kendaraan tertentu dengan lebih cepat.

Secara keseluruhan, program Sistem Parkir ini sudah menerapkan konsep dasar struktur data dan pemrograman berorientasi objek dengan baik. Queue digunakan untuk mengatur antrian kendaraan masuk dan kendaraan yang sedang parkir, sedangkan Stack digunakan untuk menyimpan riwayat kendaraan terakhir. Program ini juga memiliki tampilan menu yang sederhana sehingga mudah dipahami pengguna. Dengan adanya sistem ini, pengelolaan parkir dapat dilakukan dengan lebih terorganisir, efisien, dan mengurangi kemungkinan kesalahan pencatatan kendaraan secara manual.
